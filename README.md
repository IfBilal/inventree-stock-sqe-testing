## Reproduce
```
scripts/install.sh            # venv, dependencies, frontend build
scripts/reset.sh && scripts/start.sh
scripts/test_unit.sh          # white-box unit tests          scripts/coverage_unit.sh  (scope coverage gate)
scripts/test_api.sh api       # generated EP/BVA + business-rule API tests against the live server
scripts/test_e2e.sh           # Playwright (6 use cases x 5 flows, usability, access matrix)
scripts/perf_run.sh           # k6, 1 vs 5 users          scripts/zap_passive_run.sh  # ZAP passive
scripts/mutation_setup.sh && python tools/mutate.py   # mutation analysis (about 25 min)
```
Tool versions: `docs/TOOL_VERSIONS.md`. Everything runs without Docker (SQLite; SonarQube from the zip distribution on JDK 21; in CI SonarQube is a service container).

## Results at a glance (details in the documents)
* In-scope coverage (33 functions): **100 % statements, 99.3 % branches** over 33 functions (one unreachable branch, defended).
* Unit 342 passed (0 expected failures); API 253 passed + 27 strict xfail (loose typing / unvalidated audit parameters of upstream); E2E 57 passed (0 expected failures); API coverage criteria 100 %.
* Mutation: **mutmut 3.8.1** (real run, 652 mutants on `stock/serializers.py` + `stock/models.py`): 509 killed, 107 survivors, every one classified (51 equivalent, 56 outside the add/remove scope; raw 82.6 %, in-scope 90.0 % raw / 100 % after excluding the equivalents); plus our own runner with the 4 custom business-rule operators on the final code: 263 mutants, 254 killed, 9 equivalent → 100 % adjusted (96.6 % raw). Adjusted scores rest on the team's documented equivalence rulings (`docs/MUTATION.md`).
* Defects: 12 recorded (`docs/DEFECTS.md`); **8 fixed through pull requests merged after a green pipeline** (DEF-01 #13, DEF-02/03/04 #17, DEF-06 + SEC-01/02 #18, A11Y-01 #15); SEC-03 accepted (issue #9 closed as an accepted risk); DEF-05, A11Y-02, UX-01 open (Medium/Low) — 3 issues (#5, #11, #12) are open on GitHub; the two pull requests the pipeline blocked (#14, #16) are closed without merging and kept as evidence.
* **Release decision: HOLD** — EC-1 and EC-2 met; EC-3 not met: at 5 users failures are 0 % (were 19.5 %) but p95 is 545–556 ms against the declared 500 ms (`docs/COMPLETION_REPORT.md`).
