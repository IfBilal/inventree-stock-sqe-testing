## Reproduce
```
scripts/install.sh            # venv, dependencies, frontend build
scripts/reset.sh && scripts/start.sh
scripts/test_unit.sh          # white-box unit tests          scripts/coverage_unit.sh  (scope coverage gate)
scripts/test_api.sh api       # generated EP/BVA + business-rule API tests against the live server
scripts/test_e2e.sh           # Playwright (6 use cases x 5 flows, usability, access matrix)
scripts/perf_run.sh           # k6, 1 vs 5 users          scripts/zap_passive_run.sh  # ZAP passive
scripts/mutation_setup.sh && python tools/mutate.py   # mutation analysis (about 25 min)
```
Tool versions: `docs/TOOL_VERSIONS.md`. Everything runs without Docker (SQLite; SonarQube from the zip distribution on JDK 21; in CI SonarQube is a service container).
